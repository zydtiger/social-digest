# Goal

Turn bounded social collection into a useful digest without asking a paid agent
to browse large feeds. Local models score relevance, extract attributable
evidence, and cluster reports before final synthesis.

## Success criteria

- Provider request and cost reservations cap paid collection.
- Resume reuses saved responses and completed stages without duplicate billing.
- Evidence cards retain source links, exact excerpts, and source offsets.
- Daily collection can feed manual weekly synthesis.
- Weekly notes export to a configured Obsidian vault with parent backlinks.
- Standalone setup works without another configuration repository.

## Non-goals

Scheduling, Home Manager integration, vector databases, browser scraping,
automatic trading, and a shared orchestration framework.
